# UNO CAR — Atualizações

Este repositório guarda apenas os instaladores do sistema da oficina **UNO CAR Mecânica Automotiva**.
O programa instalado verifica esta página e se atualiza sozinho.

Para instalar pela primeira vez, baixe o arquivo `UNO-CAR-Instalador-x.y.z.exe` da [versão mais recente](../../releases/latest).
